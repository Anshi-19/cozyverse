# CozyVerse 🎬📚

**Your personal space to organize books, movies, and TV shows.**

CozyVerse is a Flutter application that brings your entertainment library into one place. It combines media organization, mood tracking, and personalized recommendations to create a more personal entertainment discovery experience.

## ✨ Features

### 📚 Personal Media Library
Organize books, movies, and TV shows in one application, making it easier to keep track of your entertainment interests.

### 🌿 Mood Tracking
Track your mood as part of your entertainment experience.

### 🎯 Personalized Recommendations
Discover recommendations designed to make finding your next book, movie, or TV show more personal.

### 🚀 Onboarding Experience
An onboarding flow introduces users to the application before they explore its main features.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK installed and configured
- A supported device, emulator, or simulator

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Anshi-19/cozyverse.git
cd cozyverse
```

**2. Install dependencies**

```bash
flutter pub get
```

**3. Run the application**

```bash
flutter run
```

Select a connected device or emulator when prompted.

For platform-specific setup requirements, refer to the official [Flutter documentation](https://docs.flutter.dev/).

## 🧪 Testing

The project includes a `test/` directory for Flutter tests.

Run the available tests using:

```bash
flutter test
```
